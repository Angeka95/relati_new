# Relati, buscador especializado de Jurisprudencia

Relati es una herramienta avanzada diseñada para facilitar la búsqueda y consulta de jurisprudencia. Su objetivo es optimizar el acceso a información legal relevante, permitiendo a profesionales y estudiantes encontrar precedentes judiciales de manera rápida y eficiente.
